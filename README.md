## Preview locally
1. Extract the ZIP.
2. Keep `index.html` and the `assets` folder together.
3. Open `index.html` in a browser. For the best development experience, use VS Code with Live Server.

## Publish free with GitHub Pages
1. Create a new GitHub repository for the portfolio.
2. Upload `index.html`, the `assets` folder, and this README.
3. Open the repository's **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. After deployment finishes, use the site URL shown in Pages settings.

Official guide: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
